🧠 Build Your Second Brain

Obsidian + an AI agent that lives inside your notes.

~15 minutes. Free to start. Works on Windows, Mac, and Linux.

📋 What we're doing
1 Install Obsidian
2 Write CLAUDE.md
3 Choose Claude or DeepSeek
4 Install the agent
5 Use it

What is a second brain?

Short version: you keep all your notes, plans, projects, and ideas in Obsidian (a free app). You connect an AI agent that can read those notes, write new ones, search for things, and help you think. The AI reads a file called CLAUDE.md that you write — it tells the AI what you're working on and how you like to work. The result: an assistant that actually knows your context, not one you have to explain everything to every time.

Longer version: this is the setup we use to produce Less Than Zero — the radio show, the research, the scripts, the planning. It works for anything: creative projects, work, personal planning, studying, writing. The pattern is always the same. What you put in the vault is up to you.

0. Before you start

✅ You need these
  • A computer — Windows, Mac, or Linux
  • 5–15 minutes of attention
  • A web browser to download things
  • For Claude: a Google account or email to sign up
  • For DeepSeek: a credit/debit card (they'll charge ~$2)
⚠️ You don't need
  • Programming knowledge
  • A powerful computer
  • To understand how AI works
  • To pay for anything (unless you choose Claude Pro)
  • A PhD in anything

1. Install Obsidian

  1. Go to obsidian.md and click the big download button. It'll pick your OS automatically.
  2. Install it like any other app — open the downloaded file, follow the prompts.
  3. Open Obsidian. It'll ask you to "Create a new vault". Click that.
  4. Pick a name — anything you want. "My Brain" is fine. "Second Brain" is fine.
  5. Where to put it:
    • 🪟 Windows: C:\Users\YOURNAME\Documents\Obsidian\My Brain — create the Obsidian folder in Documents first, then put your vault inside it.
    • 🍎 Mac: /Users/YOURNAME/Documents/Obsidian/My Brain — same idea, Documents → Obsidian → vault.
    • 🐧 Linux: /home/YOURNAME/Documents/Obsidian/My Brain — same pattern.
    Putting it in Documents keeps it findable. The Obsidian folder keeps things tidy if you ever have more than one vault.
  6. Click Create. You'll see an empty vault with a "Welcome" note. That's it — Obsidian is ready.
✅ Verify: you should see the Obsidian window with a file explorer on the left, a note open in the middle, and nothing else. The note probably says "Welcome to Obsidian!"

2. Create your CLAUDE.md

This is the most important file in your setup. It's the instruction manual the AI reads every time it starts. A good CLAUDE.md makes the AI useful. A bad one (or none) and the AI is just a generic chatbot that doesn't know you.

📝 What to put in it
  • What this vault is for
    "This is my personal planning vault" or "I'm writing a novel" or "This is for my small business"
  • A name for your AI
    Let the AI pick its own name — it sticks and becomes part of the vibe. "I'll call you Peel" or "You sound like a Sam."
  • How you want to work together
    Friendly and conversational? Blunt and numbers-driven? A collaborator who keeps you on track?
  • Key folders and what's in them
    /Projects/ for active work, /Journal/ for daily notes, /Archive/ for old stuff
  • What you need from them
    "Research artists for my radio show" / "Be blunt about my spending" / "Help me write — I draft, you polish"
  • Rules and boundaries
    "Never delete without asking" / "Don't touch the /Private/ folder"
❌ What NOT to put in it
  • Passwords or API keys
  • Credit card numbers
  • Private keys or secrets of any kind
  • Anything you wouldn't want an AI service to read

Both Claude and DeepSeek process this file on their servers. Treat it like something you'd email to a smart colleague.

How to create it
  1. In Obsidian, click the New note button (or press Ctrl+N / ⌘N).
  2. Title it CLAUDE.md (exactly that — capital letters, .md extension).
  3. Write your instructions. Start simple. You can always add more later.
📄 Starter template — copy this
# CLAUDE.md

Hey — welcome to my vault. This is my second brain. Everything I'm working on lives here, and you're my thinking partner. Feel free to be yourself.

## Pick a name

Give yourself a name — something that fits how we'll work together. Keep it. Introduce yourself when we start. I'll use it.

## What I'm working on
- [Main project — what it is, where it lives in the vault, what stage it's at]
- [Side projects — anything else you should know about]

## How we work
- Be friendly and conversational. You're a collaborator, not a tool.
- Read my files before acting. The context is in the notes.
- If you're not sure about something, ask. Better to clarify than guess.
- Keep me on track — I can get distracted. Gentle nudges are welcome.

## Where things live
- /Projects/ — active work
- /Journal/ — daily notes and reflections
- /Reference/ — things to keep, rarely change
- /Archive/ — old stuff, still searchable

## Rules
- Never delete or move files without asking
- Don't touch anything in /Private/
- If I'm going in circles, tell me

## What I need from you
[Be specific. Examples: "Research artists for a weekly radio show," "Track my spending and be blunt about it," "Help me plan a house renovation," "Write with me — I draft, you clean up."]
✅ Verify: in Obsidian's file explorer (left sidebar), you should see a file called CLAUDE.md. Click it — your instructions should be there.
💡 Why is it called CLAUDE.md? The name comes from Claude (Anthropic's AI), but it's become the universal convention. Claude Code, Hermes, Cursor, Codex, OpenCode — they all look for CLAUDE.md. It's not a Claude-only thing; it's simply the standard filename the entire ecosystem agreed on.

3. Pick and install your AI agent

Both options below give you the same result: an AI that can read and write files in your vault. Pick one. You can always switch later.

🔧 Option B — Hermes Agent + DeepSeek

What you're installing: hermes — an open-source agent from Nous Research, configured to use DeepSeek's AI models. You'll need a DeepSeek API key (free to create, pay-per-use).
Step-by-step

  1. Open Terminal.
  2. Install Hermes: 
    curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash
  3. Get a DeepSeek API key:
    1. Go to platform.deepseek.com
    2. Sign up (email or Google)
    3. Go to "API Keys" → create a new key → copy it
  4. Configure Hermes to use DeepSeek: 
    hermes config set provider deepseek
hermes config set model deepseek-chat
hermes config set api_key YOUR_DEEPSEEK_KEY
    Replace YOUR_DEEPSEEK_KEY with the actual key you copied. It starts with sk-.
  5. Navigate to your vault: 
    cd /Users/YOURNAME/Documents/Obsidian/My\ Brain
  6. Start Hermes: 
    hermes

Platform-specific notes

🪟 Windows

WSL is required for both Claude Code and Hermes. Here's the full setup:

  1. Right-click Start → Terminal (Admin)
  2. Run: wsl --install
  3. Restart your computer
  4. On restart, a Linux terminal opens. Set a username and password (simple is fine — it's just local)
  5. You're done. WSL is installed forever. Open it anytime from the Start menu.

Vault location: put your Obsidian vault at C:\Users\YOURNAME\Documents\Obsidian\My Brain. In WSL, that's /mnt/c/Users/YOURNAME/Documents/Obsidian/My\ Brain. Obsidian opens it normally in Windows; the AI agent reaches it through WSL at the /mnt/c/... path.

🍎 Mac

Everything runs natively. The only prerequisite is Node.js:

brew install node

No Homebrew? Install it from brew.sh first — it's the Mac package manager, you'll use it forever.

Finding your vault path: in Finder, right-click your vault folder, hold Option, click "Copy [name] as Pathname". Or just drag the folder into Terminal after typing cd .

🐧 Linux

Everything runs natively. You probably have Node.js — if not:

# Ubuntu/Debian
sudo apt install nodejs npm -y

# Fedora
sudo dnf install nodejs npm -y

If npm install -g gives permission errors, fix npm permissions (2-minute fix).

How you actually use it — day to day

Here's the physical process. Once it's installed, this is what you do every time.

  1. Open your terminal. On Mac: Spotlight → Terminal. On Windows: Start → WSL or Ubuntu. On Linux: you know where it is.
  2. Go to your vault. Type the command for your OS exactly as shown — replace YOURNAME with your username and My Brain with whatever you named your vault:
    cd /mnt/c/Users/YOURNAME/Documents/Obsidian/My\ Brain
    🪟 Windows (WSL)
    cd /Users/YOURNAME/Documents/Obsidian/My\ Brain
    🍎 Mac
    cd /home/YOURNAME/Documents/Obsidian/My\ Brain
    🐧 Linux
    The \ before Brain is important — it tells the terminal the space is part of the name. The AI can only see the folder you start it from, so this step matters.
  3. Start the AI. Type claude or hermes and press Enter. It'll greet you — if you set up a name in CLAUDE.md, it'll introduce itself by that name. It tells you it's read your CLAUDE.md.
  4. Talk to it. Type what you need in plain English. "Update my finances." "Research this artist." "What did I say about the house in my last journal entry?" "Draft a reply to this email." It reads your files, writes new ones, searches across everything. You talk. It works.
  5. End the session. Press Ctrl+C (or type /exit in some tools). The AI goes away. Your files stay. Your CLAUDE.md stays. Next time you start it, it remembers everything you told it in CLAUDE.md — but not what you chatted about last session. If something from last session matters, put it in a note.

💡 What to expect
  • It greets you by name. If your CLAUDE.md asks it to pick a name, it'll use the same one every time. "Morning — Sam here. What are we doing?"
  • It reads CLAUDE.md fresh each session. Update it as projects change. The AI always starts from current context.
  • It only knows what's in your vault. It can't browse the web unless you ask it to search. It can't see other folders. It works inside your notes.
  • It writes to your vault. New notes, updated trackers, drafts — they appear in Obsidian. You can open them, edit them, delete them. They're your files.
  • You're driving. The AI suggests, drafts, researches, organises. You decide. If it gets something wrong, tell it. It'll fix it.
  • Session ends, files stay. The conversation vanishes when you close the terminal. Everything it wrote to your vault stays. That's the point.
Real projects running this way
📻 Weekly radio show prep

Every Thursday, a 2-hour live radio show. The AI handles research, writing, and planning.

Chris does: picks the tracks, writes a brief in AI Guidelines.md — "here's the Qobuz playlist, the closer is Iron Maiden, Moment in History is these three tracks, new releases to highlight are X and Y."

The AI does: researches every artist and track — chart positions, album context, release history, trivia. Fact-checks names, dates, and connections. Handles production logistics like file tagging, caption timing, and scheduling. Chris does the creative work — track ordering, scripting, tile art. The AI is the researcher and the organiser, not the voice.

Result: the research that used to take 3–4 hours of Googling is done in minutes. Chris spends his time on the creative decisions — what to play, what to say, how to say it.

⚖️ Less Than Zero's AI policy is clear: the AI handles admin and research. Creative work — tracklist ordering, tile art, social scripting — stays human. The show is one person's taste and one person's voice.

📅 Daily journal with memory

Every evening, a journal entry. The AI helps reflect and remember.

Chris does: talks through his day — what happened, what's on his mind.

The AI does: pulls out highlights, lowlights, and the one thing that sat with him. Tracks habits. Cross-references previous entries ("you mentioned feeling this way last Tuesday too — pattern?"). Surfaces things he might have forgotten.

Result: a journal that actually remembers what you wrote yesterday. Not a diary — a second memory.

💰 Financial tracking (Peel)

A single Personal Finances.md file. The AI takes on a persona — blunt, numbers-driven.

Chris does: exports Monzo CSV, drops it in the vault, says "update the finances."

The AI does: parses the bank export, updates the budget tracker, flags spending anomalies, calculates how much Plata is left, reminds him his monthly card budget is £400 and he's at £312 with 6 days to go. No small wins. No sugarcoating.

Result: a financial advisor that doesn't charge £200/hour and actually reads the numbers.

🏠 House sale project

Selling a house. Multiple estate agents to coordinate. Budgets to track. A chain to manage.

Chris does: has conversations, makes calls, makes decisions.

The AI does: maintains the project document with a dated activity log of every call, email, and development. Compares agent valuations. Tracks the budget calculator as real numbers come in. Flags new listings in the target area. Keeps a running summary of where things stand.

Result: a project manager that never loses track, never forgets to log a call, and always knows exactly what happened when.

Making it yours

The CLAUDE.md is the whole game. A good one turns the AI from a generic chatbot into something that knows your projects, your preferences, and your rules. As you use it, you'll find yourself adding to it — "actually, always use this format," "don't touch these folders," "here's how I think about this."

Let it pick a name. One of the first things a good CLAUDE.md does is ask the AI to name itself. It sounds small, but it changes the dynamic — you're talking to Peel, or Sam, or whoever they decided to be. The name sticks across sessions. A named AI is a collaborator. An unnamed one is a tool.

That's the second brain emerging. The AI learns how you think because you told it — and it shows up with a name and a voice you recognise.

Troubleshooting

The tool didn't install to a place your terminal can find. Try:

  1. Close and reopen your terminal (this refreshes the command path)
  2. If that doesn't work: npm install -g @anthropic-ai/claude-code (or the Hermes install command) again and watch for errors
  3. If you see permission errors: fix npm global permissions

You probably started the AI from the wrong folder. Make sure you cd into your vault folder first. To check where you are: type pwd (print working directory). It should show the path to your vault folder.

Windows/WSL: remember your C: drive is at /mnt/c/ — so C:\Users\YOURNAME\Documents\Obsidian\My Brain becomes /mnt/c/Users/YOURNAME/Documents/Obsidian/My\ Brain

Node.js isn't installed. See the platform notes above for your OS. On Linux: sudo apt install nodejs npm -y (Ubuntu/Debian) or sudo dnf install nodejs npm -y (Fedora).

  1. Check your key is correct: hermes config get api_key
  2. If it looks wrong, set it again: hermes config set api_key YOUR_KEY
  3. Make sure you've added credit to your DeepSeek account at platform.deepseek.com
  4. Verify your provider: hermes config get provider should say deepseek

Your CLAUDE.md is probably too vague or the AI didn't read it. Try:

  1. Restart the AI and say "Read CLAUDE.md first"
  2. Add more detail to CLAUDE.md — be specific about what you're working on
  3. If the file is empty or very short, the AI has nothing to work with. Fill it out.
